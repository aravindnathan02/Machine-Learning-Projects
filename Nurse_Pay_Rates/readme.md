# Healthcare Compensation Analytics

### Situation
> Healthcare organizations struggled with compensation planning \
> Lack of data-driven insights for nurse pay \
> Need for real-time market analysis \
> Complex variations across 15 US metros

### Task
> Analyze 250K nurse pay records \
> Develop predictive models for compensation trends \
> Create accessible tool for compensation analysis \
> Enable seasonal pay strategy adjustments

### Action
> Built machine learning pipeline using multiple architectures \
> Deployed Streamlit web app for real-time analysis \
> Implemented Random Forest, XGBoost, and LSTM models \
> Created interactive visualization tools \
> Developed features for seasonal adjustments

### Result
> Achieved 0.93 R² score in pay predictions \
> Reduced planning time by 30% \
> Enabled data-driven compensation strategies \
> Provided real-time market insights \
> Facilitated efficient seasonal pay adjustments
